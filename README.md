# 김의현 — Personal Portfolio

HTML, CSS, Vanilla JavaScript로 만든 개인 프로필/포트폴리오 사이트입니다.

## Features
- 2026 스타일의 다크 브랜딩 UI
- 마우스 반응형 Hero Glow
- Magnetic CTA 버튼
- Floating glass cards
- Scroll reveal animation
- 반응형 모바일 레이아웃
- About / Work / Skills / Contact 구성

## Tech
HTML5 · CSS3 · JavaScript

## Reference
인터랙티브 Hero, cursor interaction, glassmorphism, motion UI의 아이디어를 CodePen 사례들을 참고해 독자적으로 구성했습니다.
